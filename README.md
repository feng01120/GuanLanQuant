# 观澜 QuantDesk

> 版本 1.1.5 · 白底双工作区（研究台 / 专业终端）· 软件设计与实现责任归属：**@烬羽鱼**
>
> 1.1.5 修复短周期集成权重在命中率低于 42% 时产生复数并触发预热崩溃的问题；补新浪实时报价能力注册、修复组合表列宽截断、资讯区口径与情绪关键词重复，并继续保留 1.1.4 的关窗/退出稳定性修复。最终构建进一步修正 Logistic/KNN 命中率计算、东财 push2 熔断跨进程保留、Windows 退出阶段的 Qt DLL 卸载卡死、报告表格全宽与净值平直刻度等问题。

面向 A 股的 Windows 桌面多维研判终端：把**技术、资金、估值、情绪、宏观、人文**六个维度装进同一张评分表，给出 **T+1 / T+2 短周期**与 **5 / 10 / 20 日长周期**的统计倾向，并在每小时自动重拉数据、重算因子、重估模型权重。

> 本项目是研究工具，不是投资顾问。所有概率均为历史样本上的统计倾向，不构成收益承诺；A 股存在涨跌停、停牌、复权、流动性与政策冲击，回测无法完全复现真实成交。

## 0. 直接使用（无需 Python）

解压 `GuanLanQuant-Windows-x64.zip`，双击 `GuanLanQuant.exe`。首次启动会在 exe 同级创建 `data/`、`logs/`、`reports/`，并联网预热；之后双击即用。

需要源码运行或二次开发，见第 1 节。

## 2. 双工作区与十一个页面

程序只有一个窗口、一套自选池与缓存，左侧用「研究台 / 专业终端」切换工作区。研究台看结论，专业终端看盘面，避免把 K 线、六维评分、预测卡全部塞进一页。

| 工作区 | 页面 | 看什么 |
| --- | --- | --- |
| 研究台 | **总览** | 四大指数、市场宽度、情绪仪表、成交额/涨停、自选池、人文日历、快讯、校准日志 |
| 研究台 | **个股研究** | 结论摘要、六维评分条与贡献、多空辩论、交易员动作/仓位/止损/目标、风控清单、因子依据表 |
| 研究台 | **每日荐股** | 收盘复盘、热门板块研判、未来 3 个交易日收盘涨幅 ≥3% 的历史类比概率候选、风险标签 |
| 研究台 | **周期预测** | T+1、T+2、5/10/20 日概率与区间扇形图、样本外命中率、集成权重、T+1 策略净值、校准曲线 |
| 研究台 | **宏观人文** | CPI/PMI/PPI/GDP/M2、汇率、利率代理、黄金原油、行业板块、情绪历史、人文日历 |
| 研究台 | **组合风控** | 持仓市值/浮盈/日盈亏、波动/VaR/最大回撤/Sharpe/集中度、再平衡建议、DRY-RUN 审批 |
| 研究台 | **研判报告** | 一键生成 Markdown / HTML / PDF 研报，浅色打印版 |
| 专业终端 | **K 线终端** | 报价条、折线/蜡烛双形态、日/周/月 K、均线、成交量、MACD、右侧筹码分布（估算） |
| 专业终端 | **公告事件** | 交易所公告与相关资讯分栏，公告双击打开原文，资讯附本地情绪分 |
| 系统 | **插件生态** | 10 个插件、能力索引、优先级回退链、冲突提示、健康检查、运行日志 |
| 系统 | **设置** | 自选池、校准间隔、历史长度、单票仓位上限、宏观/人文开关、缓存清理、运行机理 |

全应用为白底浅色主题；A 股沿用红涨绿跌。K 线主图默认折线（收盘价 + MA20 虚线），可切蜡烛（阳线空心红、阴线实心绿，叠加 MA5/MA20/MA60）；日/周/月切换只影响主图与指标，右侧筹码始终按日 K 估算。

**筹码口径必须诚实**：公开接口没有逐笔成交与真实持仓成本，本软件的筹码图用近 420 根日 K 的成交量、按典型价 `(H+L+2C)/4` 分 40 档，并做半衰期 120 日的时间衰减；输出收盘获利占比、平均成本、5%/95% 价格区间与集中度 `(P95-P5)/(P95+P5)`。它只是“成交量分布的估算”，不是交易所逐笔筹码，也不提供所谓“主力筹码”。

顶栏右侧的「立即校准」可手动触发一次完整周期；左侧状态灯显示交易时段（盘前/盘中/午休/盘后/休市）。行情报价默认 20 秒刷新，完整研判默认每小时一次，非交易时段也运行（用最新收盘数据）。

## 3. 六维评分与权重

| 维度 | 默认权重 | 主要输入 |
| --- | --- | --- |
| 技术 | 30% | MA/MACD/RSI/KDJ/BOLL/ATR、趋势斜率、支撑压力、量价结构 |
| 资金 | 15% | 5 日主力净流入占成交额、量比、换手、流动性 |
| 估值 | 10% | 近 3 年价格分位、PE/PB、市值 |
| 情绪 | 17% | 中文财经新闻词典打分、市场宽度、涨跌停、成交额分位 |
| 宏观 | 16% | PMI、CPI、PPI、GDP、M2、USD/CNY、国债 ETF、商品 |
| 人文 | 12% | 节假日/事件日历、产业主题与消费场景、季节性 |

融合输出：`total`（-100~+100）、`verdict`（强势/偏多/中性震荡/偏空/弱势）、`signal`、`radar`、各维 `contributions`、`confidence`。权重并非固定真理，可在插件与设置中调整；每小时周期会用滚动样本外表现重估短周期集成权重。

### 短周期（T+1 / T+2）

- 21 个特征：动量、波动、均线偏离、RSI/KDJ、量能、资金流、情绪、宏观代理等。
- 三个子模型：Ridge 回归（收益）、Logistic IRLS（方向概率）、历史形态 kNN 类比（`AnalogMatcher`，窗口 12、邻居 28）。
- 滚动 walk-forward：前 70% 定权，后 30% 样本外评估；Platt 校准；区间至少 ±1.28σ；条件收益区分上涨/下跌情形。
- 页面上的「命中率 / IC / n」是**样本外**结果，不是未来承诺。

### 长周期（5 / 10 / 20 日）

- 以 3 年估值分位、EWMA 波动率、六维总分为条件。
- 对残差做 bootstrap 蒙特卡洛（默认 2600 条路径、25 个交易日），输出各周期的上涨概率、中位收益、VaR 与最大回撤，以及 `q5/q25/q50/q75/q95` 扇形区间。
- 5/10/20 日分别做样本外验证，避免只报一个周期的最好看的数字。

### 每日荐股（3 日事件概率）

- 只在收盘后生成正式结果；盘中打开显示“盘中预览”，并用当时最新数据计算。
- 候选池取全市场成交额榜前 100（剔除 ST/退市/新股，成交额 ≥3 亿、换手 0.8%–25%、市值 ≥30 亿），并补充当日强势板块成分股。
- 对每只候选取最近 320 根日 K，按 5 日/20 日动量、RSI(14)、量比寻找 45 个历史相似形态，统计这些形态出现后第 3 个交易日收盘涨幅 ≥3% 的比例，再用板块热度、市场宽度做小幅修正。
- 输出“重点关注 / 观察 / 弱信号”，并强制展示历史类比区间、下沿风险、波动率与弱市提示；概率不是收益承诺。
- 荐股页不展示资金流列，也不把资金流作为概率修正项，避免备用数据源缺失时口径漂移。
- 结果按交易日写入 `data/cache/recommend-YYYY-MM-DD-final.json`，完整结果缓存 30 分钟；指数/板块/候选都在、仅市场宽度等字段缺失时，使用 5 分钟短缓存并在页面标注“数据不完整”。
- 数据源异常时：指数用腾讯日 K 兜底，板块与成分股切到新浪行业口径；涨跌家数与两市成交额用新浪全市场分页补；新浪不提供板块涨跌家数，页面对应列显示“--”，不伪造数值。

### 多智能体研判

六位分析师（技术/资金/估值/情绪/宏观/人文）→ 多头研究员与空头研究员各自立论 → 交易员给出动作、仓位上限、建仓区间、止损（收盘 - 2.2 ATR）、目标（max(压力位, 收盘 + 3 ATR)）与盈亏比 → 风控官检查减持、亏损、立案、诉讼、质押、退市、处罚、冻结等风险词，叠加事件临近、长短周期背离、低置信度。这里的“智能体”是**规则化角色分工**，未调用任何 LLM，输出可复现、可审计。

## 4. 数据来源（实测可用性，2026-11）

| 数据 | 主通道 | 回退 | 说明 |
| --- | --- | --- | --- |
| 实时报价 | 东方财富 `push2` | 腾讯 `qt.gtimg.cn`、新浪 | 多源按优先级回退 |
| 日线/5 分钟 K | 东方财富 `push2his` | 腾讯 `ifzq`、新浪 | 本地 SQLite 缓存 + 增量 |
| 资金流 | 东方财富 `fflow` | — | 主力/超大/大/中/小单 |
| 市场宽度/涨跌停 | 东方财富 `ulist`、`push2ex` | — | 涨停池、跌停池 |
| 新闻 | 东方财富 `np-listapi` | — | 中文财经词典打分 |
| 公告 | 巨潮资讯 | 东方财富 `np-anotice-stock` | 沪深参数不同，已适配 |
| 汇率 | 中国外汇交易中心 `CcprHisNew` | — | USD/CNY 等 |
| 宏观 | 东方财富数据中心 | — | CPI/PMI/PPI/GDP/M2 |
| 行业板块 | 东方财富 `clist` | 新浪行业 `newSinaHy` | 行业字段取 `f100`，不是 `f127`；新浪口径缺主力资金与涨跌家数 |

**明确不可用/已降级：**

- 国家统计局 `data.stats.gov.cn` 直连被 WAF 403，宏观改用东方财富数据中心转发口径。
- 北向资金实时披露已停止，软件不展示“北向净流入”，避免伪造。
- 10 年期国债收益率直连拿不到，用国债 ETF `511010` 作为利率代理，页面标注“代理”。
- 新浪实时行情需要特定 Referer，未作为主通道。

所有请求带按域名 Referer、限速、重试、磁盘缓存；接口失败时回退旧缓存并标注数据时间，不静默编造。

## 5. 每小时“修改”到底改什么

`HourlyEngine` 每个周期执行：

1. 重拉指数、自选池报价、K 线增量、资金流、新闻、公告、宏观、汇率。
2. 重算技术/资金/估值/情绪/宏观/人文六维因子。
3. 重跑短周期 walk-forward 与长周期蒙特卡洛，更新概率、区间、置信度。
4. 用最近样本外表现重估集成权重，写入 `forecasts` 与 `weights`。
5. 生成新的研判摘要、交易计划、风险清单；UI 跨页刷新。
6. 记录 `cycles` 与插件健康状态；失败不阻塞下一周期。

间隔可在设置页调整为 30–240 分钟，默认 60 分钟。行情报价另有 20 秒轻量刷新，不触发重算。

## 6. 插件结构（借鉴综述里的“清单 + 能力注册 + 优先级回退”）

```
plugins/
  datasource_eastmoney/manifest.json   priority 10  public     11 项能力
  datasource_official/                 priority 5   official
  datasource_tencent/                  priority 40
  datasource_sina/                     priority 60
  factor_technical/                    factor
  factor_sixdim/                       factor（覆盖六维）
  model_short/                         model
  model_long/                          model
  research_multiagent/                 research
  strategy_portfolio/                  strategy
```

清单示例：

```json
{
  "id": "datasource.eastmoney",
  "name": "东方财富行情",
  "version": "1.0.0",
  "api": "guanlan-1",
  "kind": "datasource",
  "capabilities": ["quote.realtime", "bars.daily", "flow.main", "news.feed"],
  "entry": "app.plugins.datasource_eastmoney:EastmoneySource",
  "priority": 10,
  "authority": "public",
  "endpoints": ["push2.eastmoney.com", "push2his.eastmoney.com"],
  "enabled": true
}
```

内核行为：

- 扫描 `plugins/*/manifest.json`，校验 `api=guanlan-1`。
- 按 `capabilities` 建索引，同一能力多插件按 `priority` 升序排列。
- `call()` 取最高优先级；失败自动 `call_chain()` 回退，并记录健康状态。
- 启动时做冲突检测：同一能力被多个插件注册时给出提示（不是错误）。
- `health_all()` 汇总每个插件的成功/失败/延迟；插件页可见。

新增数据源只需建目录、写 `manifest.json`、实现 `fetch_*` 方法，无需改主程序。插件入口由内核注入 `http/settings/store`，便于复用限速、缓存与持久化。

## 8. 打包为 EXE（可选）

```bat
build_exe.bat
```

产物在 `dist\GuanLanQuant\GuanLanQuant.exe`（单目录模式，启动快、依赖齐全）。打包后：

## 9. 已知边界

- **不接实盘、不下单**。组合页只有 DRY-RUN 建议，审批复选框只影响界面提示。
- **不接入 LLM**。研判文案由规则模板生成，避免不可复现与幻觉。
- 北向资金、10Y 国债收益率无可靠公开直连，已用代理/留空并标注。
- 成交额分位在极端缩量日可能很低（例如 1%），这是历史分位的真实结果，不是 bug；页面同时给出绝对成交额。
- 再平衡按 100 股整手，资金不足 1 手时 `delta_shares=0`，属正常约束。
- 涨跌停、停牌、ST、退市整理期股票的概率模型会偏乐观，需人工复核。
- 首次预热受网络与接口限速影响，可能 1–3 分钟；失败会自动回退旧缓存。

## 10. 研发说明

本项目的插件分层、能力注册、优先级回退、冲突检测、健康检查，以及“分析师团队 → 多空辩论 → 交易员 → 风控官”的研判流程，参考了用户提供的《金融工具生态综述》中 DSH 金融插件与 TradingAgents 式多智能体思路；**未安装、未调用** akshare、OpenBB、Qlib、Hikyuu、vn.py、Fincept 等开源库，数据接入、指标、模型、回测与 UI 均为本项目自行实现，便于控制依赖、口径与离线可复现性。
